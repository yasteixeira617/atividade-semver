# Atividade SemVer

**Nome:** Yasmim Teixeira  
**Turma:** 3DS

## Descrição

Este projeto foi desenvolvido para a atividade avaliativa de Versionamento Semântico.
O objetivo é praticar os conceitos de MAJOR, MINOR e PATCH, utilizando Git e GitHub
para controlar as versões do projeto.

## Versão

A versão escolhida é a **1.0.0**, pois representa a primeira versão estável do projeto,
contendo os arquivos necessários para a atividade.

## Justificativa da versão 1.0.0

A versão 1.0.0 foi escolhida porque esta é a primeira versão estável do projeto, com os arquivos necessários para realizar a atividade de Versionamento Semântico.


## Reflexão

O Versionamento Semântico é importante porque organiza as versões de um projeto de forma clara e padronizada. O MAJOR indica mudanças que podem quebrar a compatibilidade. O MINOR representa novas funcionalidades sem quebrar o que já existia. O PATCH é utilizado para correções de erros. Com o Git e o GitHub, é possível acompanhar as alterações e manter um histórico do projeto. Dessa forma, fica mais fácil controlar as versões e entender o desenvolvimento do software.
